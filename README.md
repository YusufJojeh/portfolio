# Yusuf Jojeh — Backend & Business Systems Engineer

A bilingual portfolio for backend and business-systems work across commerce, ERP/CRM, SaaS and AI-enabled workflows. The site presents employer contributions separately from personal projects and labels project maturity clearly.

## Stack

Next.js, React, TypeScript, Tailwind CSS, Framer Motion and next-intl.

## Run locally

```bash
npm install
npm run dev
```
