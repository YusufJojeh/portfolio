# Engineering Portfolio

## Problem

Make engineering work understandable through clear contribution, architecture, evidence, and accessible navigation.

## Architecture

Next.js and React.js render the portfolio. TypeScript structures content and components; next-intl supports English and Arabic. Tailwind CSS and Framer Motion support presentation and interaction.

## Stack

Next.js, React.js, TypeScript, next-intl, Tailwind CSS, Framer Motion, Playwright.

> This overview describes the repository scope. See the existing documentation below for setup, configuration, and verification requirements.
