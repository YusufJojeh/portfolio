# Yusuf Jojeh's Engineering Portfolio

A bilingual Next.js site for my work as a Full-Stack Software Engineer with a focus on backend systems, production reliability, and applied AI. Engineering case studies cover my contribution, the operating workflow, the architecture, and how the work was verified.

## Run locally

```bash
npm ci
npm run dev
```

Open [the English site](http://localhost:3000/en) or [the Arabic site](http://localhost:3000/ar).

## Verify

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

The GitHub Actions workflow runs the Playwright suite against a production build.
